# Archived operations guides

These guides were removed from the active documentation on 2026-08-25 after a
review found that they mixed current behavior with superseded release,
storage, host-registration and cluster assumptions.

- [`embedded/`](embedded/) preserves the former host, release, stdio and viewer
  guides;
- [`deployment/`](deployment/) preserves the former Docker, Kubernetes, HTTP
  MCP, TLS, schema and smoke-test guides.

They are historical evidence, not an operational contract. Current operations
start at [`docs/operations/README.md`](../../../docs/operations/README.md).
