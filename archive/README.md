# Archive

This directory preserves historical KMP material that is useful for audit,
reproduction, or provenance but is not part of the current product surface.

- [`docs/`](docs/README.md) — superseded architecture decisions, product plans,
  operations guides, migrations, integrations, research notebooks, and
  showcase recordings, including the
  [2026-08-26 full documentation snapshot](docs/audit-2026-08-26/ARCHIVE.md);
- [`artifacts/`](artifacts/) — recorded benchmark and experiment outputs;
- [`k8s/`](k8s/) — historical Kubernetes jobs and vLLM manifests;
- [`containers/`](containers/) — retired container definitions;
- [`run-configs/`](run-configs/) — historical experiment configurations.

For current user and operator documentation, start at
[`docs/index.md`](../docs/index.md). Current release assets live in
[`distribution/`](../distribution/).
