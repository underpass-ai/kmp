Usage: kmp-mcp export [file] [--about <about>]... [--repair-pending] [--overwrite-committed]

--about matches an opaque about exactly and may be repeated. Filtered bundles preserve aggregate revisions and use bundle-local event positions starting at 1.

With no file, export writes the project's committed `.kmp/memory.jsonl`. A full export first catches the store up with a committed file a pull brought ahead, and export refuses to replace a committed file whose events it would not keep; --overwrite-committed replaces it anyway.
