Rules:
- Write only what the supplied sources justify. The example is illustrative,
  not evidence for the current task. Use the actual about, actor, times and labels.
- Give every member a unique local id, kind, summary and evidence. Common labels
  union with each member's labels. Every member needs at least one membership.
  Label values are arrays; all values are preserved. Shared labels do not prove
  alias identity, synonymy or any semantic relation.
- Links may target @id anywhere in the same packet, including later members.
  For an existing target, copy the returned canonical ref. Never invent a ref.
- Every non-structural link needs why and evidence. Why explains the connection
  between these endpoints; evidence names the observation or source proving it.
  Do not invent links or relabel weak evidence as causal. Independent facts may
  be unlinked. Supported weak links include follows/procedural,
  answers/evidential and uses_background/evidential when the source justifies them.
- Rich links to stored memories require read_context containing the refs actually
  inspected or reached through temporal navigation, Wake, Ask or Trace. Local
  packet members need no fabricated inspected_refs. Cross-about equivalence
  requires the actual kmp_relate proposal and its supported equivalence relation.
- For non-English summary, supply summary_en in plain English while retaining
  numbers, identifiers and acronyms. Retrieval uses that rendering; citations
  retain the literal summary. Never alter the source text to pass validation.
- A semantic_delta is an explicit member with its source, prior and resulting
  state and justified relations. No intent, scope, current or semantic_delta
  object exists at the root of the writer contract.
- Preserve unknown occurrence times as absent. observed_at is observation time;
  ingestion time is recorded by the store. Supply validity only when evidenced.
- Omit options.dry_run for a normal commit; preview only when requested. Strict
  validation is the default. A validation failure commits none of the packet.
- Reuse one idempotency_key for an exact retry of a logical write. An unchanged
  accepted packet is not a second event.
- To attach search renderings later, use a separate packet with about, actor,
  observed_at and search_summaries: [{"ref": "returned canonical ref",
  "summary_en": "faithful English rendering"}]. The stored text, kind, labels
  and clocks are preserved. Do not combine search_summaries with memories.
- To connect two memories that already exist, use a separate packet with about,
  actor, observed_at and relations: [{"from": "returned canonical ref",
  "to": "returned canonical ref", "rel": "supports", "why": "...",
  "evidence": "..."}]. Both sources keep their text, evidence, coordinates,
  labels and metadata; only the link and its evidence are new, and each carries
  its own observation. Never resubmit a stored memory as a record to link it.
  Do not combine relations with memories or search_summaries.
