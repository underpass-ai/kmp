# Archive

Dated records: design notes, increment logs, acceptance matrices and
performance evidence from the work that led to 1.0. They are **not
instructions**. Each one was true on the day it was written; commands, tool
names, arguments and numbers in them may no longer hold. Check anything you
reuse against the current code, `kmp-mcp --help` and the live `tools/list`.

Historical numbers and model names stay as they were measured (for example
`jev-1.13.0` in a dated record).

Evidence under `artifacts/` that these records cite was removed from the
repository before 1.0. It is still in the Git history: read it at the
[`v0.27.0` tag](https://github.com/underpass-ai/kmp/tree/v0.27.0/artifacts).

Older material (the tree before 2026-08-26) is in the
[`v0.5.0` Git tree](https://github.com/underpass-ai/kmp/tree/v0.5.0/archive).
