## Author's change description

Fixes #25.

## Three calls to answer two questions

`kernel_wake` returned `summary`, `wake`, `proof`, `warnings` — none of them carrying a temporal coordinate. So "where was I, and what changed since?" cost three calls, and the middle one existed only to recover a timestamp:

```
kernel_wake    { about }                              # where was I
kernel_rewind  { from: {time: now}, limit: 1 }        # ...just to learn the newest observed_at
kernel_forward { from: <that timestamp> }             # what changed
```

Wake had that information in hand. It walked the neighbourhood to build the packet.

## What lands

`WakeResponse` gains `resume_cursor` — field 5, a compatible addition on the wire — and the MCP wake response gains a `resume_cursor` object. It is the newest coordinate the packet covers, ordered by time and then sequence, which is the order the store writes in.

```json
"resume_cursor": {
  "ref": "project:kmp:decision:undo-is-a-write",
  "time": "2026-08-16T20:10:00Z",
  "sequence": 1
}
```

## Two things only a real store showed

**The time is `occurred_at`, else `observed_at`, else `ingested_at`.** My first pass read `occurred_at` alone and returned `null` against a store where 25 relations carried coordinates — every one of them written with `observed_at` instead. Relations like that are ordinary, not degenerate, and a cursor that ignores them is a cursor that is usually absent.

**`null` when nothing carries a coordinate.** Memory written without temporal coordinates is ordinary too, and inventing a cursor for it would hand the caller a bookmark pointing nowhere.

## What this deliberately does not do

The kernel still does not remember where each reader got to. That would be state about the reader rather than about the work, and it would need a reader identity the protocol does not have. The cursor is the caller's to carry; this hands it to them instead of holding it for them.

## Verified against a real store

The cursor matches the maximum of all 25 coordinates in the same packet — computed independently from `proof.path` and compared — and `kernel_forward` from it returns zero entries, which is correct: nothing is newer than the newest.

## The contract is vendored twice

Which means this touches both proto copies, both fixture copies, the JSON schema, the fixture-shape test that pins the response's key set, and the skill that teaches the flow. `check-vendored-contract.sh` is green.

## Gates

`quality-gate.sh` green — 807 tests, four of them new: the cursor is the maximum, sequence breaks a time tie, an `observed_at`-only coordinate still anchors a resume, and memory without coordinates yields no cursor.
