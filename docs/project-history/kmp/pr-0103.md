- keep the graph-aware relevance tuple and searchable relation context through answer diversification
- make primary relevance dominate bounded novelty and use stable evidence refs as the final tie-breaker
- promote distinct supported claims before repeated citations consume the five-item answer core
- add a regression where relation-`why` relevance would previously be displaced by four weak unique-term distractors

## Root cause
