## Author's change description

Cierra las 6 alertas abiertas de Dependabot:

| Alerta | Severidad | Fix |
| --- | --- | --- |
| rustls-webpki — DoS via panic en CRL BIT STRING (GHSA-82j2) | HIGH | 0.103.10 → 0.103.14 |
| rustls-webpki — CRL Distribution Point (GHSA-pwjx) | MEDIUM | 0.103.14 |
| rustls-webpki — name constraints wildcard y URI (GHSA-xgp8, GHSA-965h) | LOW ×2 | 0.103.14 |
| rand — unsoundness con custom logger (GHSA-cq8v) | LOW | 0.9.2 → 0.9.5 |
| tokio-tar — PAX Header Desynchronization (GHSA-j5gw, sin parche upstream) | HIGH | testcontainers 0.24 → 0.28 sustituye tokio-tar por astral-tokio-tar 0.6.4: el crate vulnerable desaparece del lock |

La copia residual de rustls-webpki 0.102.8 venía de async-nats 0.46; el bump a async-nats 0.50 (que exige ^0.103.10) la elimina — el lock queda con una única copia 0.103.14.
