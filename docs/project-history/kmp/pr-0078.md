## Author's change description

## Summary

- Add a container-backed test that leaves one related endpoint intentionally unmaterialized.
- Prove the default bundle contains only the real decision node and its valid relation.
- Prove the rendered context contains neither the placeholder endpoint ID nor placeholder markers.
- Mark placeholder filtering as implemented in the testing matrix.

## Why

Relation projection deliberately creates placeholder endpoints to support eventual convergence. Those storage-level artifacts must never leak through the node-centric query boundary into recovered context.
