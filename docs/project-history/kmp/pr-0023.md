## Author's change description

First of the three event-store use cases. The other two — delta-since-last-session and memory-in-the-repo — follow in their own PRs.

## Why

KMP is hard to evaluate before you have written anything into it. The viewer opens empty, `kernel_wake` finds nothing, and the first write is the one call the strict writer **cannot** make on a fresh about (#14). The first five minutes show none of what the product is for.

## What ships

**`plugins/kmp/demo/checkout-latency.jsonl`** — eight events, exported from a real store rather than hand-written, so it is by construction a bundle the current binary can read.

**`/kmp:demo`** (and `/kmp-demo` for Codex) — imports it into a data directory of its own, then *uses* it: wake, ask, trace. The command tells the agent not to simulate the answers if the session has no `kernel_*` tools.

It never touches the project's store. `import` already refuses a non-empty one, but refusing is not the point — a demo that *could* write near real memory is a demo nobody should run.

## The incident has a wrong turn in it, on purpose

Checkout p99 triples after a deploy → the pool looks saturated → the obvious change is rolled back → **the rollback does not help** → the real cause was a client timeout cut in the same release train, turning every slow request into six → capped retries fix it → a constraint stops it recurring.

That shape is what makes *"which attempt introduced this assumption"* and *"what did we believe at 15:05"* worth asking. A demo where everything goes right demonstrates nothing a README cannot.

The graph carries every rich relation class — `supports`, `chosen_because`, `contradicts`, `derived_from`, `verified_by`, `satisfies_constraint`. `kernel_trace` from the first symptom to the closing constraint returns a six-hop path at 0.83 causal density.

## Three gates, because a file does not follow the code that reads it

| Gate | What it catches |
|---|---|
| `crates/kmp-adapter-embedded/tests/demo_bundle.rs` | the bundle stops importing, or loads but has lost its story — it asserts the eight entries by name and that the `contradicts` edge still carries its why and its evidence |
| `scripts/ci/kmp-plugin-smoke.sh` | the bundle is missing from the plugin, or its header disagrees with its contents |
| `scripts/plugin/package-kmp-plugin.sh` | stages `demo/`, so the release tarball carries it and not just the marketplace install |

Without the first, a change to the event format or the projection derivation would leave `/kmp:demo` broken on every new install while every other test stayed green — the failure surfacing in front of the one person we most wanted to impress.
