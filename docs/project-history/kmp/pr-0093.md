## Author's change description

## Summary

- recall supported constraints across reasonable paraphrases by combining direct evidence terms with bounded causal, motivational, and constraint graph context
- keep a direct lexical eligibility floor and content-first ranking so relation context cannot promote unrelated citations
- diversify retained evidence for compound questions and expose `proof.matched_terms` / `proof.matched_relations` without leaking scores or thresholds
- add an embedded MCP regression covering morphology, reordered clauses, deterministic repeats, a semantic-context distractor, and an unrelated UNKNOWN control

## Root cause

Strict recall evaluated each evidence item in isolation. A fact split between evidence text, its supported memory entry, and a semantic relation could therefore fail the focus threshold under a reasonable paraphrase. Blindly adding graph terms creates the opposite risk, so the implementation only lets semantic context complete focus after the citation itself passes the existing direct lexical floor.
