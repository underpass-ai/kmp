## Author's change description

## Why

The marketplace manifest was named `underpass` but lived in this repository. Two consequences:

- **`made` had no one-line install at all.** `/plugin marketplace add underpass-ai/made` fails with "Marketplace file not found" — that repo has no manifest, and it could not have one named `underpass` without colliding with this one. The coordination plane was the only product without the install path we lead with.
- The organisation's marketplace belonged to one product, so listing a sibling meant this repo publishing an entry for a repo it does not own.

## What changed

The manifest moves to **[underpass-ai/plugins](https://github.com/underpass-ai/plugins)**, a manifest-only repository. Entries use a `git-subdir` source pointing at the plugin directory inside each product repo, so a plugin stays released and versioned where it lives and the marketplace never carries a copy. That source form is what the official Anthropic marketplace uses for 233 of its 286 entries.

```
/plugin marketplace add underpass-ai/plugins
/plugin install kmp@underpass
/plugin install made@underpass
```

Every instruction here is repointed: README, plugin README, `docs/operations/mcp-stdio.md`, `kmp-doctor.sh` and `install-kmp-plugin.sh`.

## Verified

`/plugin marketplace remove underpass` then add the new one. Nothing else changes; the plugin names are the same.
