## Author's change description

## What changed

- preserve a bounded `kernel_ask` answer, one cited reason, and minimal proof when the serialized response exceeds the token budget
- preserve the `kernel_wake` object and resume cursor under the same fallback
- make summaries and truncation metadata explicitly report omitted items and shortened text
- add regressions for default, compact, 400-token ask, and oversized wake packets

## Why

The v0.1.7 fallback could replace an oversized recall response with a summary-only packet. That packet claimed an answer existed while removing `answer`, `because`, and `proof`, so callers could not recover or audit the result.

## Impact

Budgeted recall remains within the requested cl100k envelope while retaining the semantic payload needed by clients. No storage format, migration, or database behavior changes.

Closes #71.
