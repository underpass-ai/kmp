## Author's change description

Renames the project to **KMP by Underpass**, matching the protocol it already implements.

## What is renamed

| Layer | From → To |
|---|---|
| 24 crates | `rehydration-*` → `kmp-*` |
| Domain types | `RehydrationBundle` / `Stats` / `Mode` / `Application` → `Kmp*` |
| Helm chart | `charts/rehydration-kernel/` → `charts/kmp/` |
| Container image | `ghcr.io/underpass-ai/rehydration-kernel` → `.../kmp` |
| Environment | 30 × `REHYDRATION_*` → `KMP_*` |
| Binaries | `rehydration-mcp` → `kmp-mcp`, `rehydration-neo4j-migrate` → `kmp-neo4j-migrate` |
| Branding | `Underpass Kernel` → `KMP by Underpass` (README, NOTICE, AsyncAPI, Sonar) |

## What is deliberately *not* renamed

Runtime contracts keep their names so nothing already deployed breaks:

- **Proto package** `underpass.rehydration.kernel.v1beta1` and its messages. Only `go_package` changed, following the repo URL. The gRPC service full names on the wire are unchanged.
- **NATS subjects** (`rehydration.graph.node.materialized`, …) and the **`REHYDRATION_PROJECTION`** JetStream stream — renaming these orphans existing streams.
- **OTel metric names** (`rehydration.kmp.*`, `rehydration.quality.*`), documented as a contract in `docs/observability.md`.
- **Metrics JSON schema** (`rehydration_point_hit`, …), which must keep matching the preserved `artifacts/`.
- **Inference prompt fixtures** under `api/examples/inference-prompts/` — tests pull them in via `include_str!`, and editing them would silently change what the model is asked.

Historical material is untouched as a record of what happened under the old name: `docs/archived`, `docs/research`, `docs/product/operator-training-runs`, `artifacts` and `docs/paper`.

Note that `RehydrationBundle` exists on **both** sides — domain and proto — so the two were separated file by file. The safety net is that prost fixes the generated names, so any over-rename fails to compile rather than passing silently.
