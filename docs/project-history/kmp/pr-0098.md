## Author's change description

## Summary

Replaces the serialize-then-drop recall truncator with a deterministic core-plus-prefix projection gateway for `kernel_ask` and `kernel_wake`.

- preserves the complete cited Ask core and a stable Wake core before expansion
- orders expansion once, independently of budget, with `compact ⊆ balanced ⊆ full`
- enforces a normative 10,000-byte serialized ceiling; keeps cl100k tokens advisory
- exposes truthful per-section accounting and stateless opaque continuation cursors
- rejects cursors when bound arguments or the selected memory snapshot change
- removes the O(n²) full-packet tokenize/drop loop
- keeps generative summarization out of the deterministic kernel boundary

This lands after #94 fixed the metadata cliff and #95 normalized each evidence body to one canonical copy.
