## What ships

**Two agent hosts can share one memory** ([ADR-018](https://github.com/underpass-ai/kmp/blob/45ba56d9890f7e0bbc382bc6a9d4973247a1977b/docs/adr/ADR-018-multi-process-embedded-store.md)). The default engine takes one process at a time, so Claude Code and Codex CLI on the same project meant whichever started first owned the memory. The store now has a seam and a second engine behind it — WAL-mode SQLite, opt-in via `--features sqlite`. redb stays the default and the default stripped binary is **byte-identical at 13,121,304 bytes**; the cost lands only on the people who need the fix.

**Three things the event log could always support, now reachable.** Memory that lives in the repository, catching up on what changed, and undoing a decision by superseding it rather than deleting it. Two of the three needed no new capability at all — only reach — which is why there is still no eleventh move.

**And the defects only visible by installing it as a user**: `kernel_write_memory` reporting success without writing, the plugin's MCP server never starting, `cargo install --features sqlite` failing, the marketplace having moved. Each now has a gate.
