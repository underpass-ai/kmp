## Summary

- extract `kernel_ask` ranking from transport into a dedicated deterministic graph-aware reranker
- preserve the direct lexical eligibility floor while using bounded typed relation features (`rel`, class, direction, endpoints, evidence-backed `why`) for eligible candidates
- group scarce core citations by supported claim, bound compound-query reranking to 64 candidates, and handle superseded claims explicitly
- add an embedded MCP regression for the ADR-018-equivalent SQLite/redb question with weak lexical distractors and three-run determinism
- document the evaluation contract and local cost comparison
