## Author's change description

## What this releases

The plugin fix from #10, plus the documentation restructure from #9.

**Fixed**
- The plugin launcher no longer dies on a marketplace install. It execs `bin/kmp-mcp`, which is gitignored and therefore only exists in a release package, so a marketplace install produced a plugin whose MCP server exited 127 telling the user to build a bundle they cannot build. Both launchers now fall back to `kmp-mcp` on `PATH`.
- `serverInfo.name` was `kmp-kmp`, a blanket-rename artifact visible in every client's `initialize`. Now `underpass-kmp-mcp`.

**Changed**
- README opens with the two editions and the per-host install, leading with the plugin; new `docs/editions.md`; operations index grouped by edition; integration guide renamed to `made-kmp.md`.
