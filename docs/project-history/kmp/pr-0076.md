## Author's change description

## Summary

- Add a container-backed regression test for a relation event that arrives before both endpoint node events.
- Prove the late node projections replace both placeholders without losing the relation-only `ADDRESSES` edge.
- Mark the out-of-order convergence scenario as implemented in the testing matrix.

## Why

KMP consumes node and relation subjects independently, so delivery order is not guaranteed. This test protects the convergence behavior at the real NATS → Neo4j → gRPC boundary.
