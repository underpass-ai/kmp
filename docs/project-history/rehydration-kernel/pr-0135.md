## Author's change description

Milestone **E5**: installation is one command; a version tag produces every artifact.

- **`release` workflow**: tag push → stripped + checksummed `rehydration-mcp` for linux x86_64/aarch64, macOS arm64/x86_64, windows x86_64, attached to the GitHub release via `gh` (no new third-party actions). `workflow_dispatch` runs the same matrix without publishing — pipeline verifiable without cutting a release.
- **`scripts/install/install.sh`**: platform detection, checksum-verified download, installs to `~/.local/bin`, prints Claude Code + Codex registration snippets.
- **`docs/operations/embedded-release.md`**: release flow, install paths, and the binary↔`FORMAT_VERSION` compatibility matrix (a format bump ships its migration tool in the same release, by rule).
- **README**: embedded distribution goes from *(planned)* to **shipped, primary** with quickstart — the public face of the embedded-first decision. Roadmap: E4 accepted (Claude Code + Codex tested live; Copilot parked), E5 in progress.
