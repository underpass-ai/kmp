## Author's change description

## Problem
Service and Deployment shared `selectorLabels` with Neo4j StatefulSet:
- `kubectl logs deployment/rehydration-kernel` showed **neo4j** logs
- `kubectl port-forward svc/rehydration-kernel` hit neo4j pod (no grpc port → error)
- Service load-balanced across kernel AND neo4j pods

## Fix
Add `app.kubernetes.io/component: server` to Deployment and Service selector.
Neo4j already has `component: neo4j`.

## Breaking change
Deployment selector is immutable — requires `kubectl delete deployment` before upgrade.
