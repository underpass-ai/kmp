## Summary

P0 fixes from an exhaustive documentation audit of the kernel. Every change was verified against the current code surface (the audit ran 18 agents that extracted 162 ground-truth facts from the crates, then adversarially verified each material finding).

This PR is **docs-only** and groups the five highest-confidence corrections:

- **`kernel-context-api-design.md` — document `kernel_write_memory` (the missing 10th MCP tool).** The canonical KMP design doc listed only the 9 memory moves, but live MCP advertises **10 tools**: `assert_eq!(tools.len(), 10)` (`crates/rehydration-mcp/src/protocol.rs:693`), handled at `server.rs:156`. Added it as a writer-friendly helper above canonical `kernel_ingest` (defaults `dry_run = true` / `strict = true`; strict requires `current.evidence` + a `connect_to` relation — `write.rs:167/171`), and to the *Required tools* block. `kernel_remember` / `kernel_ingest_context` remain documented as hidden ingest aliases.
- **`ADR-007` — `rehydrate_session()` now emits per-role quality metrics.** The "Trade-off" said it does *not* emit quality. It does, via the same observer (`rpc = "RehydrateSession"`, `query_grpc_service_v1beta1.rs:393`). Updated the architecture diagram (3 observe sites), the context comment, and rewrote the stale bullet as an honest "Update (superseded since this ADR)" while preserving the ADR's history.
- **`api/proto/README.md` + `api/asyncapi/README.md` — fix 3 broken relative links.** They were written repo-root-relative (`api/examples/...`, `docs/migration/...`) but markdown resolves relative to the file; targets exist. Corrected to `../examples/...` and `../../docs/migration/...`.
- **`crates/rehydration-mcp/README.md` — local gRPC example port `50051` → `50054`** (the default bind, `app_config.rs:36`; `50051` only appears in test fixtures).
- **HF model card template — V6 holdout20 replay `Elapsed 7m18.7s` → `10m15.9s`.** `10m15.9s` is the canonical figure for the same `1,124 / 976 / 148` run in 5 other docs; `7m18.7s` was an outlier in a publication artifact.
