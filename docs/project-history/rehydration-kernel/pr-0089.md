## Author's change description

## What changed

- Adds Phase A multidimensional and temporal metadata to relationship explanations and proto mappings.
- Projects KMP memory dimensions, entry coordinates, evidence, and relation metadata into the kernel read model.
- Extends the MCP adapter with `kernel_goto`, `kernel_near`, `kernel_rewind`, and `kernel_forward` over live `GetContext` results.
- Makes the MCP binary installable through `cargo install --git`, fail-fast by default, and fixture mode explicit via `REHYDRATION_MCP_BACKEND=fixture`.
- Updates KMP schema, MCP docs, Helm/deploy guidance, Podman image publishing notes, and product design docs.

## Why

Phase A needs memory traversal across explicit dimensions and temporal coordinates, plus a practical MCP distribution path that Codex and other MCP clients can install without running from a checkout.

## Impact

- MCP clients can ingest KMP-shaped memory and traverse entries by dimension/time/sequence/ref.
- Live deployments expose traversal through the existing public gRPC endpoint via MCP stdio.
- Misconfigured MCP startup now fails immediately instead of silently serving fixtures.
