## Author's change description

## What changed

- round-trip entry metadata and evidence metadata/source across temporal, context, and inspect reads
- return real evidence `supports` targets
- align temporal causal density and ADR-014 telemetry with other read paths
- raise the default `kernel_goto` page to 50 entries and add structured MCP error categories
- validate coordinate dimension kinds during ingest
- add `triggers`, `authorizes`, and `verified_by`, plus the remaining typed relation explanation fields and relation coordinates
- update KMP schemas, prompt fixtures, conformance coverage, and integration documentation

## Why

Choreographer's embedded KMP conformance run showed that typed memory qualifications were accepted at ingest but lost or misreported on reads. It also exposed inconsistent temporal quality/telemetry, a one-entry default page, prose-only errors, lenient dimension validation, and a gap between the documented relation model and the MCP surface.

## Impact

KMP clients can reconstitute typed memory without private encoding conventions. The changes are additive at the protocol boundary except for stricter rejection of mismatched coordinate kinds and the larger default `goto` page.

## Root cause

Several persisted node properties and domain relation-explanation fields were not mapped into the v1beta1 response/proto surface. Temporal traversal had separate defaults and quality/observer plumbing from context reads, and ingest resolved dimension scopes without checking the declared kind.
