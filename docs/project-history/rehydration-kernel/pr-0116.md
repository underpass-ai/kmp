## Author's change description

## Qué

Presupuesto de entrada **opcional** en Wake del Kernel Memory Protocol:
`MemoryBudget.max_entries` (campo proto; `0` = sin límite) acota la evidencia que
`kernel_wake` expone a N entradas y reporta el tamaño de la cola restante vía
`frontier_size`. Es lo que habilita la **expansión de ventana con `kernel_near`**
—abrir una ventana de lectura acotada y ampliarla a través del tiempo y de varias
dimensiones— en vez de que Wake vuelque el `about` completo de una vez.
