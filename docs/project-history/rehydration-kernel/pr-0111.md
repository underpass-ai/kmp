for verified preflight before any test or operation against KMP/MCP.

Motivated by 2026-05-26 incident: stale PATH binaries (operator-session-run
and rehydration-mcp built before wire-fix commit) produced a smoke result
that was retroactively invalidated.

- rehydration-mcp smoke against a known real anchor
