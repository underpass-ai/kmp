## What's here

**`rehydration-adapter-embedded`** — `EmbeddedKernelStore`: all nine persistence ports (`GraphNeighborhoodReader`, `NodeDetailReader`, `NodeRelationshipReader`, `MemoryAboutIndexReader`, `ProjectionWriter`, `ContextEventStore`, `ProcessedEventStore`, `ProjectionCheckpointStore`, `SnapshotStore`) on **one redb file**, per the E0 ADRs:

- **ADR-012 data dir**: `FORMAT_VERSION` stamp, fail-fast on newer/older/corrupt layouts (unit-tested)
- **ADR-010 graph**: materialized by-source + by-target adjacency, anchor index, depth-bounded directed BFS and shortest-path that mirror the Neo4j Cypher semantics (incl. `MERGE ON CREATE` placeholders)
- **ADR-009 durability**: fsync per commit; append-only event log as source of truth with CAS + revision stamping
- **Replay/compaction tooling**: `rebuild_projections(derive)` (one transaction, crash-safe) + `compact_data_dir`; derivation injected via new pub `rehydration_application::projection_mutations_for_context_event`, so the adapter keeps zero application-layer dependencies
