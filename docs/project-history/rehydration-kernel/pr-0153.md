## Author's change description

## What changed

- add an embedded HTTP memory viewer backed by the local kernel
- expose the viewer through the MCP embedded-session flow
- render relation rationale, motivation, method, evidence, confidence, causal anchors, and temporal coordinates
- add smoke coverage and document operation, usage, and the ADR

## Why

Embedded users need a local, inspectable view of memory nodes and relationships without deploying the full external stack. The viewer also needs to preserve the explanatory context carried by KMP relations rather than reducing them to source, target, and type.

## Impact

Users can launch and inspect an embedded memory session through a browser while retaining the relation vocabulary and evidence recorded by the kernel.
