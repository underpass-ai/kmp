## Author's change description

## What changed
Adds the reranker-backed semantic-classification path for GraphBatch generation, plus reproducible smoke tooling and example payloads for vLLM graph materialization.

## Why
We needed a fast, low-cost semantic-class classifier that can run independently from the main generative model, and we also needed an in-cluster roundtrip smoke that validates the full path against the live kernel.

## Impact
- Rehydration testkit can classify `semantic_class` through `/score` as well as `chat/completions`
- New live GraphBatch smoke coverage for PIR/vLLM roundtrips and larger incident fixtures
- Kubernetes manifests and example runtime config now document and wire the semantic reranker
- Research and usage docs explain the model choice and the new operational path

## Root cause
The previous path only supported generative semantic classification, which made this slice heavier than necessary and left the in-cluster validation path under-specified.
