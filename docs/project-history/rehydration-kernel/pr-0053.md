## Author's change description

## Summary

- **NOT_FOUND instead of placeholder**: `GetContext`, `GetContextPath`, and `RehydrateSession` now return `NOT_FOUND` when the root node does not exist instead of silently returning a fake bundle with kind `"placeholder"` and status `"UNKNOWN"`
- **Remove tautological scope validation**: `GetContext` was calling `ValidateScopeUseCase::execute(requested_scopes, requested_scopes)` — always passing. Now returns `scope_validation: None`. The standalone `ValidateScope` RPC is unchanged
- **Require snapshot_ttl**: `RehydrateSession` no longer hardcodes `snapshot_ttl_seconds: 900`. When `persist_snapshot=true`, `snapshot_ttl` is required or the call fails with `INVALID_ARGUMENT`
- **Document reserved fields**: `include_timeline` and `include_summaries` are marked as reserved for future use
- **Add beta-status.md**: RPC maturity matrix documenting what is production-ready, experimental, or placeholder
