## Author's change description

## El síntoma

`wait-codeql-checks` falla en **toda** PR de dependabot. #144 está 15/16 en verde y bloqueada únicamente por esto.

## La causa

El *default setup* de code scanning **no lanza sus análisis por lenguaje en las PRs de Dependabot**. Publica un agregado `CodeQL` en estado neutral y nada más: no hay `Analyze (actions)` ni `Analyze (rust)`.

El gate espera exactamente esos dos, y trata tanto un check ausente como un `CodeQL` neutral como *pendiente*. Resultado: consume los diez minutos de deadline y falla.

Comprobado sobre tres PRs:

| PR | Tipo | `Analyze (*)` | `CodeQL` | Gate |
| --- | --- | --- | --- | --- |
| #110 | humana | 4 en verde | SUCCESS | SUCCESS |
| #86 | dependabot | **ninguno** | NEUTRAL | — |
| #144 | dependabot | **ninguno** | NEUTRAL | **timeout** |

## No es una regresión de #140

Conviene dejarlo dicho porque #140 tocó este mismo job. El código original empujaba tanto los checks ausentes como el `CodeQL` neutral a la misma lista de pendientes:

```js
if (!analysisState || analysisState.status !== "completed") { pending.push(analysisName); }
...
if (name === "CodeQL" && state.conclusion === "neutral") { pending.push(name); continue; }
```

Esa rama se preservó literal. Con la misma entrada, la versión anterior habría expirado igual. #140 cambió el manejo de nombres duplicados, no esto.

## El arreglo

Saltar el job en PRs de Dependabot, **igual que ya se salta en forks**.

```yaml
if: >-
  always() && github.event_name == 'pull_request'
  && github.actor != 'dependabot[bot]'
  && !(github.event.pull_request.head.repo.fork || false)
```

**No retira señal de seguridad**, porque no hay análisis que esperar: CodeQL no corre ahí en absoluto. Y `dependency-review` —el gate que sí cubre lo que una PR de dependencias cambia realmente— sigue siendo obligatorio.

Se descartó la alternativa de tratar «agregado neutral sin ningún `Analyze`» como no-aplicable: sería una regla más sutil y podría tapar un escaneo omitido en una PR humana, que es justo el caso que este gate existe para detectar.
