## Author's change description

## Summary

Addresses findings from external architecture review. Every fix comes with a test that proves the fix works.

### Token counting consistency (#11 from review)
- `BundleSection.token_count` was using `split_whitespace()` while global used cl100k_base
- Now: `RenderedSection` carries pre-computed cl100k_base token count from application layer
- **Test**: `section_token_counts_use_cl100k_base_not_whitespace`

### Remove admin gRPC service (#7, #8, #9 from review)
- Deleted admin.proto, all 5 admin RPCs, admin use cases, admin application services
- Removed from GrpcServer, proto build, all tests and fixtures (-1782 lines)
- BasicContextAgent refactored to use GetContext for focus node selection

### Validate expected_content_hash (#5 from review)
- `UpdateContext` now validates `expected_content_hash` against stored hash
- Returns `ABORTED` (Conflict) when mismatch
- Added `current_content_hash` to `ContextEventStore` trait and all 3 adapters
- **Test**: `execute_rejects_wrong_content_hash_precondition`

### Salience by semantic_class (#10 from review)
- Relationships sorted by salience: causal > motivational > evidential > constraint > procedural > structural
- Focus proximity is secondary within each salience tier
- **Test**: `causal_relationships_render_before_structural`
