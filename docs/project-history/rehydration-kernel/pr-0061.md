## Author's change description

## Summary

Complete vLLM in the loop implementation for SOTA Level 2.

### Infrastructure
- Helm NATS/Valkey sidecars with TLS (new templates)
- Warmup fix: server tolerates empty cluster (NotFound)
- Dual vLLM deployment: inference (GPU 2, mTLS) + judge (GPU 3, ClusterIP)

### LLM Evaluator
- `llm_evaluator.rs`: OpenAI-compatible client with mTLS support
- `LLM-as-judge`: semantic evaluation via separate LLM endpoint
- Configurable via env vars: LLM_ENDPOINT, LLM_JUDGE_ENDPOINT, LLM_TLS_*

### Seed Publisher
- `seed_publisher.rs`: bridges dataset generator → NATS projection events
- Converts GeneratedSeed into GraphNodeMaterializedEvent / NodeDetailMaterializedEvent

### Benchmark
- 18-config matrix: 3 scales × 2 domains × 3 relation variants
- Pipeline: generate → publish → rehydrate → vLLM inference → judge evaluation
- Results: explanatory >= structural in debug domain, reason_preserved is key differentiator

### Benchmark Results (Qwen3-8B)
```
micro/debug: explanatory=3/3, structural=2/3
meso/debug:  explanatory=1/3, structural=0/3
stress/debug: explanatory=1/3, structural=0/3
```
