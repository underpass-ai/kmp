## Author's change description

Closes milestone **E0** of the [KMP Embedded Edition Roadmap](https://github.com/underpass-ai/rehydration-kernel/blob/5f63bbb83610b39547f9846735a9c4755e4d5790/docs/product/kmp-embedded-edition-roadmap.md): the decisions that shape E1-E6, each as an ADR, with the storage spike executed and recorded.

## Decisions

| ADR | Decision |
| --- | --- |
| ADR-009 | **redb** as the embedded storage engine (spike: redb 4.1.0 vs fjall 3.1.8 vs SQLite 0.40.1 on a 102k-event corpus; reopen 2.9ms vs 1.3s vs 0.3ms, binary cost +0.7MB vs +1.25MB vs +2.1MB; pure-Rust bias upheld) |
| ADR-010 | Graph = **materialized adjacency tables** updated synchronously; no in-memory graph rebuilt at startup (session start stays O(1)) |
| ADR-011 | **Single-writer advisory lock**, fail-fast explicit error for a second session; local daemon documented as the evolution path; merge-on-read rejected on semantics |
| ADR-012 | Data dir: `REHYDRATION_MCP_DATA_DIR` > project `.kernel/` (self-gitignoring) > XDG user dir; `FORMAT_VERSION` fail-fast rules |
| ADR-013 | **One binary**: `embedded` backend behind a cargo feature in `rehydration-mcp`, composition root in new `rehydration-embedded` crate, forbidden-dependency CI gate |

The roadmap's E0 exit criteria said four ADRs; the naming/packaging deliverable got its own record, so five landed.
