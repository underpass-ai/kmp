## Log file (ADR-012 layout)
Embedded mode now journals structured JSON logs to `<data-dir>/logs/rehydration-mcp.log.<date>` (daily rotation, non-blocking writer) in addition to stderr — stdout remains pure MCP JSON-RPC. Smoke-tested against the real binary.

New `embedded-binary-gates` CI job: fails if the MCP binary's dependency graph ever grows `neo4rs`/`async-nats`/infra adapters/`rehydration-server`/`rehydration-transport-grpc`, and enforces a 16MB stripped-size budget (measured today: 13.7MB with both backends).
