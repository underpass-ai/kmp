# Runbooks

These runbooks are current, bounded procedures. They start with read-only
diagnosis, name the mutation boundary and include a verification step.

| Situation | Runbook |
|:--|:--|
| The host cannot see `kmp_*` tools or startup fails | [MCP tools are missing](mcp-tools-missing.md) |
| A local store must be recovered, shared or moved | [Embedded recovery](embedded-recovery.md) |
| A shared Kubernetes release must be rendered, deployed or updated | [Enterprise deployment](enterprise-deployment.md) |

Archived runbooks are evidence only and are not indexed here.
